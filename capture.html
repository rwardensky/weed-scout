Weed Scout capture

Updates White Ash Reserve and Crysp from any phone or computer. Their bot checks block the daily refresh, so you open the store, then tap the bookmark.

1. Connect GitHub on this device

  1. Open GitHub's new token page.
  2. Name it "Weed Scout capture". Under Repository access, pick Only select repositories → weed-scout.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Generate it and paste it below.

2. Add the bookmark

Computer: drag this button to your bookmarks bar.

Weed Scout capture

Phone: bookmark any page, then edit that bookmark: name it Weed Scout capture and replace its address with the copied code.

3. Use it

  1. Open White Ash Reserve or Crysp and get past the security check.
  2. Tap the Weed Scout capture bookmark. On Android Chrome, type "Weed Scout capture" in the address bar and pick the bookmark.
  3. This page opens, uploads the catalog, and the site refreshes in about an hour.
